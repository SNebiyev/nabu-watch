# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's **"Report a vulnerability"** button
(private vulnerability reporting) on the repository's Security tab. Do not open public issues
for security problems.

Include the affected component (API, worker, UI), the version or commit, steps to reproduce,
and the impact you observed.

## Support expectations

nabu-watch is maintained on a best-effort basis by a single maintainer. There is no
response-time guarantee. Only the latest `main` is supported; fixes are not backported.
